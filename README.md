# Portafolio de Eddy Omar SB

**[Visitar mi portafolio](https://eddyomar1.github.io/index/)**

Hola, soy Eddy Omar SB. En este portafolio reúno algunos proyectos, prácticas y trabajos técnicos que
he realizado a lo largo de mi aprendizaje y experiencia profesional.

Mi intención es mostrar de forma sencilla lo que he construido, las tecnologías con las que he
trabajado y las áreas en las que continúo desarrollándome. No es necesario descargar este
repositorio para conocer los proyectos: la mejor forma de explorarlos es visitar el sitio publicado.

## Qué encontrarás

- Proyectos web, aplicaciones, juegos y experimentos de programación.
- Trabajos de electrónica industrial documentados mediante fotografías.
- Experiencia práctica con desarrollo de software y programación de microcontroladores.
- Tecnologías que he utilizado y áreas que continúo fortaleciendo.
- Una demostración Web3 que no realiza transacciones.
- Un formulario y correo de contacto.

## Mi experiencia e intereses

He trabajado con desarrollo web, lógica de programación, interfaces, microcontroladores y sistemas
electrónicos. También tengo experiencia en electrónica industrial, especialmente en trabajos
relacionados con tableros eléctricos, cableado, protección, monitoreo y control.

Actualmente continúo ampliando mis conocimientos mediante proyectos prácticos, con especial interés
en la programación, el desarrollo de software y la integración entre software y electrónica.

## Electrónica industrial

La sección de electrónica industrial contiene una galería de trabajos que realicé durante mi
experiencia en esta área. Las fotografías permiten apreciar distintos procesos, montajes y
soluciones técnicas sin convertir esta página en una documentación interna de cada instalación.

## Cómo construí este sitio

Desarrollé el portafolio con Next.js, React, TypeScript y Tailwind CSS. Utilizo una exportación
estática para publicarlo en GitHub Pages. El formulario puede conectarse a Supabase o Formspree
cuando estos servicios están disponibles.
